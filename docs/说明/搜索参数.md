# 母岩搜索参数

预算影响候选覆盖，线程数影响并行，模拟距离属于游戏规则，不能为了提速随意改小。输出limit主要控制最终条数，通常不显著减少前面的模拟。

`--coverage game`为默认随机刻模型：旧版按区块中心严格小于128格，新版按玩家区块±模拟距离的方形，当前有效半径上限31区块。`circle`/`square`使用`--inner-radius`按最终母岩XZ计数，忽略Y，不能把数量当成游戏活跃数量。粗筛仍以晶洞来源数量选候选，自定义精排按逐母岩坐标计分，有限预算的漏热点风险仍然存在。

距离单位在后端转换：外半径和自定义内半径默认`blocks`，对应`--radius-unit`/`--inner-radius-unit`可选`chunks`；模拟距离默认`chunks`，`--simulation-distance-unit blocks`可输入160格表示10区块，150格会报错。改变统计模式或内半径使用不同断点指纹，旧模型断点不混用。

- 小范围可用`--prefilter-limit 0`完整候选；大范围用正预算。
- 历史种子9206294873968313284、1.21.1、十万半径的20万预算相对50万参照，前100热点交集95/100；不是通用召回率。
- 同种子500万半径，20万与100万预算的前100交集72/100，前10一致不足以证明整个榜单稳定。50万及更多种子的平衡仍未校准。
- auto只在达到既有规模门槛后尝试GPU；小范围GPU初始化可能抵消收益。精排仍在CPU，线程越多不保证越快。
- 对关心的任务比较预算B和2B的热点、坐标与数量变化；扩池稳定只是模型内经验，不代表真实全区域前100。

上述数字仅是特定参数下的测量摘要，不能直接套用到其他种子、范围或设备。
