# 母岩使用说明

正式程序为`build/geode-finder.exe`；`run.bat`读取`finder.json`，命令行可覆盖配置。运行不需要Java或Minecraft，OpenCL仅为可选粗筛加速。

统一配置为JSON对象，键名与CLI参数去掉--后一致；命令行覆盖配置。程序只在显式--config时读文件，run.bat负责选择本目录finder.json。输出目录默认results，默认Top100；桌面统一--desktop且不读取CLI配置。

## 参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `--seed` | `0` | 有符号 64 位种子；JSON 使用字符串 |
| `--version` | `1.21.1` | 地形模式支持1.18–1.21.11及26.1–26.3正式版 |
| `--model` | `terrain` | terrain 为局部地形修正；stone 为明确指定的纯石头对照模型，几何仍遵循所选版本 |
| `--radius`、`--center-x`、`--center-z` | `10000`、`0`、`0` | 挂机位置搜索范围，方块单位 |
| `--shape` | `circle` | circle / square |
| `--tick-radius` | `128` | 1.21.4 及以前的区块中心严格圆形距离 |
| `--simulation-distance` | `10` | 1.21.5 起的玩家模拟距离，区块单位 |
| `--threads` | `8` | 1–64 |
| `--scan-backend` | `auto` | auto / cpu / gpu；大范围有限预算自动尝试OpenCL GPU；实际选择见`stats.scanBackend` |
| `--min-geodes` | `1` | 最低活动晶洞起点数；旧 Java 对比可设 20 |
| `--min-budding` | `1` | 最低模型估计母岩数 |
| `--prefilter-limit` | `0` | 0 为完整候选；正数为按活动形状内洞数截取的粗筛预算，取整阈值两种候选取并集 |
| `--limit` | `100` | **不同热点**的数量上限 |
| `--output` | `results` | 输出目录；每次搜索写 CSV、TXT、JSON 三份正式文件 |
| `--checkpoint-dir` | 输出目录下 `checkpoints` | 自动恢复相同参数的未完成任务，覆盖CPU/GPU粗筛与局部模拟；成功导出后清理 |
| `--no-checkpoint` | 默认不传 | 禁用断点读写；原有断点保留 |

## 版本与底层计算

`--versions`列出32个正式版本入口。1.18/1.18.1与1.18.2仍使用不同的产品地形和晶洞几何分组，默认terrain；不能因为群系查询可复用同一底层类就合并完整地形。26.3结构气候由Cubiomes公共采样器提供，母岩专用地形、含水层和晶洞逻辑仍由本引擎实现。

## 查询入口

`--player-x/--player-z`重算一个挂机点；`--geode-chunk-x/--geode-chunk-z`查询一座来源晶洞的全部母岩XYZ。`--samples`执行批量模型查询。母岩不推断最佳Y，传送命令使用`~`保留高度。

桌面使用`--desktop`协议v3；CLI的`--jsonl`是另一套进度事件，不能混用。桌面默认延迟导出，点击保存才落盘；CLI直接生成CSV/TXT/JSON。

## 活动规则与模型边界

1.21.4及以前按区块中心到玩家的严格圆形距离统计，1.21.5起按玩家区块和模拟距离方形统计。多人、额外加载源等条件不在当前模型内。26.3采用独立float噪声、密度图和气候路径。

| 版本 | 晶洞与局部环境路径 |
|---|---|
| 1.18、1.18.1 | 半格距离、近似倒平方根；旧地形样条、高度滑动和含水层水/岩浆接缝规则；无远古城市、试炼密室影响 |
| 1.18.2 | 整数距离、近似倒平方根；1.18密度路由和含水层；无远古城市、试炼密室影响 |
| 1.19–1.19.3 | 整数距离、近似倒平方根；新版密度路由、深暗之域含水层排除与城市适配；无试炼密室影响 |
| 1.19.4及以后 | 精确倒平方根；按版本选择现有结构、地形与活动规则，26.3使用独立噪声路径 |

模型计算局部密度、含水层、传统雕刻、试炼/城市地形适配、试炼写入及相邻晶洞覆盖；矿井、地牢和任意加载顺序尚未完整实现，结果始终为预计数量。

截至2026-10-27，当前开放的32个Java正式版本均已有对应原版FULL区块生成的抽样对照。各版样本量不同；抽样吻合不代表任意环境下完全准确。

有限预算先筛玩家区块，可能遗漏热点；完整候选模式只是模型内不做预算截断，不是原版真实前100证明。所有开放版本默认使用terrain，旧版本也不会自动降级为stone。后端CLI和协议支持这些版本，桌面版本选项及发行包需另行更新。

## 排名与挂机点

最终按预计母岩数降序 → 距实际搜索中心距离平方升序 → X、Z升序。晶洞数只展示；粗筛候选和组内几何仍有自己的比较语义。

先按代表点归独立热点，再求组内整数挂机点，最终去除优化后重合热点；不做无限传递合并，也不固定每热点只验证五个中心。

参数折中见[搜索参数](搜索参数.md)，恢复方式见[断点续跑](断点续跑.md)。本地冻结参照与模型回归位于不提交的`tests/`，模型内一致不等于真实全区域前100；普通构建不需要这些文件。
